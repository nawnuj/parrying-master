# Parrying Master

언리얼 엔진과 C++를 이용해 개발 중인 패링 중심의 3인칭 액션 게임입니다.

## 프로젝트 목표

적의 공격을 정확한 타이밍에 패링하고 반격하는 전투 시스템을 구현하는 것을 목표로 합니다.

## 개발 환경

- Unreal Engine 5
- C++
- Blueprint
- Visual Studio 2022
- Git / GitHub

## 1주차 완료 결과

플레이어가 테스트 맵에서 이동·점프·달리기·회피·공격할 수 있으며, 공격 애니메이션의 타격 시점에 테스트 더미를 감지하고 피해를 적용할 수 있다.

테스트 더미는 체력이 0이 되면 사망 처리되며, 플레이어는 피해 구역을 통해 체력 감소, HUD 갱신 및 사망 상태를 테스트할 수 있다.

## 2주차 완료 결과

2주차 통합 테스트를 통해 적 추적과 공격, 플레이어 피해와 경직, 3단 콤보, 피격 시 콤보 취소 및 플레이어 사망 시 적 전투 중단이 함께 정상적으로 작동하는 것을 확인했다.

현재 적의 공격 간격과 플레이어 경직 시간 때문에 실제 적을 상대로 3타 콤보를 모두 연결하기 어려운 한계가 있다. 이는 3주차 패링 시스템을 통해 공격 기회를 만들고, 이후 전투 밸런스 조정에서 적 공격 간격과 경직 시간을 다시 조절할 예정이다.

다음 단계에서는 방어 및 패링 입력, 패링 가능 구간, 피해 무효화, 적 경직 및 반격 시스템을 구현할 예정이다. 공격 방향 보정과 전진 이동, 빠른 방향 회피 애니메이션과 무적 시간은 4주차 전투 폴리싱 작업에서 개선할 예정이다.

## 3주차 완료 결과

타이밍 기반 패링 입력과 적 공격의 패링 가능 구간을 구현하고, 플레이어의 패링 상태와 공격 방향을 함께 확인하여 정면에서 들어오는 공격만 패링할 수 있도록 구성했다.

패링에 성공하면 피해와 피격 반응을 무효화하고 적의 공격과 이동을 중단한 뒤 일정 시간 경직시킨다. 성공한 패링 판정은 즉시 소비되며, 짧은 반격 가능 시간 안에 공격하면 기존 Attack1을 재사용하여 첫 타격에 강화 피해 40을 적용한다.

현재 패링과 반격의 핵심 상태 흐름은 완성되었으며, 이후에는 패링 전용 애니메이션, 사운드, 이펙트, UI 피드백과 전투 밸런스를 보완할 예정이다.

## 4주차 진행 상황

공격을 시작할 때 마지막 이동 입력 방향을 확인하고, 입력 방향이 있다면 캐릭터가 해당 방향을 즉시 바라본 뒤 공격 몽타주를 재생하도록 구현했다.

이동 입력이 없는 경우에는 현재 캐릭터 방향을 유지한다. 일반 공격과 패링 반격이 분기되기 전에 방향을 보정하므로 두 공격 모두 동일한 방향 처리 방식을 사용한다.

후속 콤보를 연결하는 `TryContinueCombo()`에서도 이동 입력 방향을 다시 확인하도록 확장했다. 따라서 Attack2와 Attack3으로 넘어갈 때 현재 이동 입력 방향으로 캐릭터가 회전한 뒤 다음 Montage Section으로 연결된다.

각 공격 단계가 시작될 때 캐릭터가 바라보는 방향으로 짧게 전진하도록 코드 기반 공격 이동을 추가했다. 일반 Attack1과 패링 반격 Attack1은 몽타주 재생 성공 후 전진하며, Attack2와 Attack3은 다음 Section 연결이 확정된 뒤 전진한다.

현재 공격 전진은 `CharacterMovementComponent`에 `AddImpulse()`를 한 번 적용하는 방식이다. 기능적으로는 공격 거리를 보완하지만 애니메이션 이동과 완전히 동기화되지 않아 순간적으로 튀는 느낌이 있으며, 이후 Montage Notify 또는 Root Motion 기반 이동으로 개선할 예정이다.

회피 시작 시 짧은 무적 시간을 활성화하고, 무적 시간 중 플레이어에게 전달되는 피해를 `TakeDamage()`에서 차단하도록 구현했다. 무적 중에는 체력 컴포넌트까지 피해가 전달되지 않으므로 체력 감소, 피격 몽타주와 경직이 발생하지 않는다.

회피 재사용을 관리하는 `bCanDodge`와 현재 피해를 차단하는 `bIsDodgeInvincible`을 분리했다. 회피 쿨다운은 0.6초이며 실제 무적 시간은 0.25초이므로 회피 동작 전체가 무적 상태가 되지는 않는다.

플레이어 사망 시 회피 무적 타이머와 상태를 함께 정리하여 사망 이후 피해 차단 상태가 남지 않도록 처리했다. 재사용 가능한 체력 컴포넌트는 수정하지 않고 플레이어 캐릭터의 피해 진입 지점에서만 회피 상태를 확인한다.
