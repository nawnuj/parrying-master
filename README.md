# Parrying Master

언리얼 엔진과 C++를 이용해 개발 중인 패링 중심의 3인칭 액션 게임입니다.

## 프로젝트 목표

적의 공격을 정확한 타이밍에 패링하고 반격하는 전투 시스템을 구현하는 것을 목표로 합니다.

## 개발 환경

- Unreal Engine 5
- C++
- Blueprint
- Visual Studio 2022
- Git / GitHub

## 1주차 완료 결과

플레이어가 테스트 맵에서 이동·점프·달리기·회피·공격할 수 있으며, 공격 애니메이션의 타격 시점에 테스트 더미를 감지하고 피해를 적용할 수 있다.

테스트 더미는 체력이 0이 되면 사망 처리되며, 플레이어는 피해 구역을 통해 체력 감소, HUD 갱신 및 사망 상태를 테스트할 수 있다.

## 2주차 완료 결과

2주차 통합 테스트를 통해 적 추적과 공격, 플레이어 피해와 경직, 3단 콤보, 피격 시 콤보 취소 및 플레이어 사망 시 적 전투 중단이 함께 정상적으로 작동하는 것을 확인했다.

현재 적의 공격 간격과 플레이어 경직 시간 때문에 실제 적을 상대로 3타 콤보를 모두 연결하기 어려운 한계가 있다. 이는 3주차 패링 시스템을 통해 공격 기회를 만들고, 이후 전투 밸런스 조정에서 적 공격 간격과 경직 시간을 다시 조절할 예정이다.

다음 단계에서는 방어 및 패링 입력, 패링 가능 구간, 피해 무효화, 적 경직 및 반격 시스템을 구현할 예정이다. 공격 방향 보정과 전진 이동, 빠른 방향 회피 애니메이션과 무적 시간은 4주차 전투 폴리싱 작업에서 개선할 예정이다.

## 3주차 완료 결과

타이밍 기반 패링 입력과 적 공격의 패링 가능 구간을 구현하고, 플레이어의 패링 상태와 공격 방향을 함께 확인하여 정면에서 들어오는 공격만 패링할 수 있도록 구성했다.

패링에 성공하면 피해와 피격 반응을 무효화하고 적의 공격과 이동을 중단한 뒤 일정 시간 경직시킨다. 성공한 패링 판정은 즉시 소비되며, 짧은 반격 가능 시간 안에 공격하면 기존 Attack1을 재사용하여 첫 타격에 강화 피해 40을 적용한다.

현재 패링과 반격의 핵심 상태 흐름은 완성되었으며, 이후에는 패링 전용 애니메이션, 사운드, 이펙트, UI 피드백과 전투 밸런스를 보완할 예정이다.

## 4주차 완료 결과

공격 시작과 후속 콤보 연결 시 이동 입력 방향으로 캐릭터를 회전시키고, 각 공격 단계에서 짧게 전진하도록 구현하여 공격의 방향성과 접근성을 개선했다.

회피 전용 몽타주와 코드 기반 이동을 적용하고, Montage Notify에 맞춰 무적 시간을 활성화하여 회피 동작과 피해 차단 시점을 동기화했다.

플레이어 사망 몽타주와 마지막 자세 유지를 구현하고, 사망 후 현재 레벨을 다시 열어 플레이어와 적의 상태를 초기화했다. 통합 테스트에서 발견된 적 공격 거리 데드존은 AI Controller와 Enemy Character가 하나의 공격 거리 기준을 사용하도록 수정하여 해결했다.

## 5주차 진행 상황

UE4 Mannequin용 외부 애니메이션 `Paired_CounterPunch_PalmStrike_Att`를 UE5 Manny의 `SKM_Manny_Simple`로 리타기팅하고, 플레이어 패링 입력에 사용할 `A_Player_Parry`와 `AM_Player_Parry`를 생성했다.

패링 입력 시 `ParryMontage`를 재생하도록 `StartParry()`를 확장했다. 패링 몽타주가 지정되지 않았거나 재생에 실패해도 기존 시간 기반 패링 판정은 유지되므로 애니메이션과 전투 판정이 서로에게 필수적으로 의존하지 않는다.

실제 패링 판정 상태인 `bIsParrying`과 패링 몽타주 재생 상태인 `bIsParryAnimationPlaying`을 분리했다. 패링 판정은 기존 `ParryWindowDuration`에 따라 종료되며, 이동 제한은 패링 몽타주가 끝날 때까지 유지된다.

수평 이동 중이거나 달리기 속도가 활성화된 상태에서는 패링을 시작할 수 없도록 제한했다. 패링 몽타주 재생 중에는 이동과 달리기 입력을 차단하고, 몽타주가 종료되면 이동 제한 상태를 해제한다.

통합 테스트를 통해 정지 상태의 패링 애니메이션, 기존 패링 판정과 쿨다운, 정면 방향 판정, 적 경직과 반격 기능이 함께 정상적으로 작동하는 것을 확인했다.

적이 패링 성공을 확정할 때 플레이어에게 공격자 정보를 전달하도록 확장하고, 플레이어와 공격자의 중간 지점에 높이 보정을 더해 패링 성공 피드백 위치를 계산하도록 구현했다.

C++의 `BlueprintImplementableEvent`를 통해 `BP_PMCharacter`가 패링 성공 위치에 `NS_ParrySuccess`를 생성하고 전용 카메라 흔들림을 재생하도록 구성했다. 패링 입력만으로는 피드백이 발생하지 않으며, 실제 패링 성공 시에만 이펙트와 카메라 흔들림이 함께 실행된다.

외부 애니메이션 `Paired_PushShove_Vic`과 `Paired_CounterPunch_PalmStrike_Vic`을 적 캐릭터 스켈레톤으로 리타기팅하여 `A_Enemy_HitReact`, `A_Enemy_ParryStun`과 각각의 Montage를 생성했다.

적의 체력 변경 이벤트를 이용해 일반 피해를 감지하고, 피격 중에는 공격과 AI 추적을 제한하도록 구현했다. 일반 피격 시간이 종료되면 생존 및 전투 상태를 확인한 뒤 추적과 공격을 복구한다.

기존 패링 경직 상태에는 전용 몽타주를 연결했다. 패링 경직이 일반 피격보다 우선하도록 상태와 타이머를 정리했으며, 경직 중 반격 피해를 받아도 일반 피격 몽타주가 패링 경직 몽타주를 덮어쓰지 않도록 구성했다.

통합 테스트를 통해 일반 피격, 패링 경직, 반격 피해, 전투 복구 및 사망 시 상태 정리가 함께 정상적으로 작동하는 것을 확인했다.

패링 성공 후 생성되는 반격 가능 상태를 플레이어가 화면에서 확인할 수 있도록 `WBP_HUD`에 반격 안내 문구와 남은 시간 Progress Bar를 추가했다.

`APMCharacter`가 기존 반격 타이머의 남은 시간을 0~1 비율로 반환하도록 구현했다. HUD는 `CanParryCounter()`를 이용해 반격 가능 상태에서만 표시되며, 반격 입력으로 기회를 소비하거나 제한 시간이 만료되면 자동으로 숨겨진다.

외부 효과음의 이용 조건과 저작권 문제를 피하기 위해 패링 성공 사운드는 이번 프로젝트 범위에서 제외했다. 기존 Niagara 이펙트와 카메라 흔들림을 패링 성공 피드백으로 유지한다.

통합 테스트를 통해 패링 성공, 반격 기회 소비, 시간 만료 및 레벨 재시작 이후 UI 표시 상태와 Progress Bar가 정상적으로 갱신되는 것을 확인했다.
