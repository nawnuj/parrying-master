# Parrying Master

언리얼 엔진과 C++를 이용해 개발 중인 패링 중심의 3인칭 액션 게임입니다.

## 프로젝트 목표

적의 공격을 정확한 타이밍에 패링하고 반격하는 전투 시스템을 구현하는 것을 목표로 합니다.

## 개발 환경

- Unreal Engine 5
- C++
- Blueprint
- Visual Studio 2022
- Git / GitHub

## 1주차 완료 결과

플레이어가 테스트 맵에서 이동·점프·달리기·회피·공격할 수 있으며, 공격 애니메이션의 타격 시점에 테스트 더미를 감지하고 피해를 적용할 수 있다.

테스트 더미는 체력이 0이 되면 사망 처리되며, 플레이어는 피해 구역을 통해 체력 감소, HUD 갱신 및 사망 상태를 테스트할 수 있다.

## 2주차 진행 상황

기존 체력 시스템을 재사용하는 기본 적 캐릭터를 구현하고, 플레이어 공격으로 피해를 받아 사망하도록 연결했다.

적 AI Controller와 NavMesh 경로 이동을 추가하여 적이 플레이어를 추적하고 일정 거리에서 멈추도록 구현했다. 적 전용 Animation Blueprint는 실제 이동 속도를 기준으로 Idle과 Walk 상태를 전환한다.

적이 공격 거리 안에서 이동을 멈추고 플레이어 방향으로 회전한 뒤 공격 몽타주를 재생하도록 구현했다. 공격 애니메이션의 타격 시점에는 Pawn 대상 근접 공격 판정을 실행하고 플레이어에게 피해를 적용한다.

적 AI가 플레이어의 체력 컴포넌트에서 사망 상태를 확인하도록 개선했다. 플레이어가 사망하면 적의 이동, 공격 몽타주, 공격 쿨다운 및 현재 공격 대상을 정리하고 AI 동작을 중단한다.

적 메시와 Capsule이 카메라 채널을 무시하도록 설정하여 적 공격 중 Spring Arm이 순간적으로 줄어드는 현상도 해결했다.

플레이어의 체력 변화를 감지하여 피해를 받았을 때 피격 몽타주와 경직 상태가 시작되도록 구현했다. 피격 중에는 이동, 점프, 달리기, 회피 및 공격 입력을 제한하고 진행 중인 공격 몽타주와 공격 타이머를 정리한다.

피격 중 추가 피해는 체력에 적용되지만 피격 애니메이션과 경직 타이머는 다시 시작하지 않는다. 체력이 0이 되는 피해는 일반 피격 반응을 생략하고 기존 사망 처리로 연결되도록 구분했다.

다음 단계에서는 현재 한 종류뿐인 플레이어 공격 애니메이션을 세 종류로 확장하고, 공격 입력 시 1타부터 3타까지 연결되는 연속 공격 시스템을 구현할 예정이다. 각 공격은 Animation Montage Section으로 구분하고, 정해진 입력 가능 구간에 들어온 공격 입력을 예약하여 다음 공격으로 연결할 계획이다.

연속 공격 이후에는 플레이어 사망 애니메이션과 레벨 재시작을 구현하고, 회피 애니메이션과 무적 시간 및 방어·패링 시스템으로 확장할 예정이다.
